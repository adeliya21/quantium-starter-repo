# Quantium Web Report Simulation

## About the Project

An interactive data visualization dashboard built with Python and Dash to explore Pink Morsel sales over time. The application displays sales trends in a line chart and allows users to filter the data by region, making it easier to compare sales patterns across different geographic areas.

This project was developed using the Quantium starter repository as part of a data analytics learning project.

## Features
- Interactive Sales Visualization: Display sales trends over time using a Plotly line chart.
- Regional Filtering: Filter sales data by East, South, West, North, or view all regions.
- Dynamic Dashboard: Automatically update the visualization when a region is selected.
- Custom Styling: Use a pink-themed interface with customized chart colors and layout.

## Technologies Used
- Python — Application logic and data processing
- Pandas — CSV data loading, sorting, and filtering
- Dash — Interactive web dashboard
- Plotly Express — Interactive line chart visualization
